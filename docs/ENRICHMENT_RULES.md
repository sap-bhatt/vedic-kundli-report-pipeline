# Enrichment pass rules (for research agents)

Goal: bring an existing layer file up to the strict standard without losing good content.

1. Read the schema in `docs/LIBRARY.md` first. Edit ONLY your assigned files; scratch files only in a scratch folder outside the repository (delete at the end).
2. Keep every existing claim that is properly sourced. For any field content without a cited source, either find a
   source and cite it, or remove it (empty string / empty list). `phrasing_guidance` is the only field that may be your own.
3. Add at least THREE modern authorities per file where they speak to the placement. Readable online (found by earlier jobs):
   B.V. Raman, *How to Judge a Horoscope* vols 1-2 and *Hindu Predictive Astrology* (archive.org); David Frawley;
   Sanjay Rath; Andrew Foss; James Braha; Bhrigu Sutras commentary. Komilla Sutton / K.N. Rao only if you can read them.
   Classical full texts found readable: Phaladeepika (siva.sh, wisdomlib), Brihat Jataka (Sastri, archive.org),
   Jataka Parijata (Sastri, archive.org), Saravali English (search archive.org / Santhanam), BPHS (enjoylearningsanskrit.com).
4. Read pages in full; mark "(via summary)" honestly whenever you did not read the page itself.
5. Fill `disagreements` wherever sources differ. Re-check `confidence` after enrichment.
6. Paraphrase; never copy long passages; cite text + chapter/verse + URL. Valid UTF-8 JSON; keep ids, keys and order unchanged.
7. Finish and save one file completely before starting the next.
8. Reply in under 120 words: files updated, sources added per file (classical vs modern), share of fields emptied or newly
   sourced, and which flagged items were fixed or could not be fixed.
